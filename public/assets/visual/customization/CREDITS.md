# Appearance atlas

Original Echoes of Dante complete-figure paintings, reused from the existing authored sources. Three complete face/hair sets per presentation, eight views, offline registered neck crops. Palette changes are baked once on appearance/equipment changes. No third-party assets.

Revision 0.1.200 adds original short-curly and low-bun paintings, eight views for each body, to the versioned `*-v2.png` atlases. Created with the built-in image generation tool using the project's existing art as reference; alpha extraction and registration occur offline. Existing sets are preserved. Production sources, prompts and processing are documented in `docs/2d-refinement/source200/README.md`. No assets from other game franchises or external asset licenses were introduced.
