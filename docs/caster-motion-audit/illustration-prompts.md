# Original motion repaint — built-in imagegen

Original head/torso paintings are retained. Six complete lower-body production sheets are copied into source-art and packed offline. Initial full-character walk sheets were rejected for missing/truncated rows; they are not consumed by the game. Front views have own masculine/feminine reference; back/side technical legwear is shared and fitted to each original body's waist without per-axis stretching. Contact/passing counterpart mirroring is an explicit export choice, not runtime leg-strip movement.
