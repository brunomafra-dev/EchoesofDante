# Hunter — kit articulado 0.1.67

Produzido offline com a ferramenta interna **imagegen**, usando `public/assets/visual/characters/star-hunter-poses.png` como referência de identidade. Alpha transparente preservado. O script técnico apenas recorta, dimensiona e empacota partes; não desenha novas poses.

Uma tentativa de seis poses de caminhada repetiu os apoios em vez de alterná-los. Foi descartada. O kit separado permite controlar apoio, passada e flexão dos joelhos explicitamente, sem depender dessa repetição.
